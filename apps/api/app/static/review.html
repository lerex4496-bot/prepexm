MODEL PROVIDERS

Routing is by role, not by vendor. A role with nothing configured falls back to a related role and the result is labelled as single-stage — VISION and EMBED never fall back, because a text model cannot see or embed.
Keys are never sent back to this page. Leave the key field blank to keep the stored one; type a new value only to replace it. Prefer key env (e.g. NVIDIA_API_KEY), which keeps the secret in .env and out of the database.
